# Third-party notices

The local Anthropic adapter adapts OAuth request shaping and billing-header
logic from [pi-anthropic-auth](https://github.com/gotgenes/pi-anthropic-auth),
revision `d83b174f52a00fd7a0d89fbcd4abb4253f3c4e44`, and uses the OAuth protocol,
credential format and Claude Code compatibility conventions documented in
[Pi](https://github.com/earendil-works/pi).
